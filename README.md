## ⚙️ How to Install and Run Locally

### 1. Clone the Repository
```bash
git clone https://github.com/techcodemn/Aman_Portfolio.git
cd Aman_Portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 How to Create a Production Build

```bash
npm run build
```
Creates an optimized, minified production bundle inside the `dist/` directory.

To test the production build locally:
```bash
npm run preview
```

To run code linting:
```bash
npm run lint
```

## 🌐 Deployment Information

This portfolio is optimized for modern static hosting providers:

### Option 1: Vercel (Recommended)
1. Push this project to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **Add New Project**.
3. Import `aman-kumar-portfolio`.
4. Vercel automatically detects the Vite framework and builds from `dist/`.
   *(Pre-configured `vercel.json` rewrite rule is already included in root)*.

Or deploy directly via CLI:
```bash
npx vercel --prod
```

### Option 2: Netlify
1. Go to [netlify.com](https://netlify.com) and drag-and-drop the `dist/` folder or connect your GitHub repository.
2. Build command: `npm run build`, Publish directory: `dist`.
   *(Pre-configured `public/_redirects` is already included)*.
